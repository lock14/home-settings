# IDE workspace, multiplexer, and portable shell architecture

This document specifies the runtime mechanics of `bin/ide` (`libexec/ide_lib/`), `dotfiles/.tmux.conf`, `dotfiles/.config/nvim/lua/solarized/`, and portable Zsh and Bash shell integration.

## Single-window geometry and pane lifecycle

- **Single-window layout**: All visible IDE panes (`AI`, `Editor`, and `Shell`) live inside a single `tmux` window named `ide` (`allow-rename off`), defaulting to the 3-pane inverted-T layout (50% by 75% AI top-left, 50% by 75% Editor top-right, 100% by 25% Shell bottom) or 2-pane side-by-side (`--2pane`). Never create hidden `_swap` windows.
- **Keybinding isolation**: Never bind `bind -n C-h/j/k/l` in `dotfiles/.tmux.conf` or map `<C-h/j/k/l>` in Neovim terminal mode (`"t"`), preserving `Ctrl+L` (clear), `Ctrl+J` (newline), `Ctrl+K` (kill line), and `Ctrl+H` (backspace) in shells and AI CLIs, and keep `Alt+s`, `Alt+m`, and `Alt+Arrow` unbound in Tmux root tables so AI CLI shortcuts (`agy` `swarm.board` and `prompt.submit_alternate`) and shell word navigation pass straight through. Keep `<C-h/j/k/l>` internal to Neovim splits (`internal_split_nav`), use `Alt+h/j/k/l` (`M-h/j/k/l`) for universal 2D focus navigation across Neovim (`n/i/v/t`), Vim (`n/v/i`), and Tmux, use `Alt+Shift+H/J/K/L` (`ide _internal swap left|down|up|right`) for directional swapping, and use `Alt+Shift+Left/Down/Up/Right` (`Prefix + H/J/K/L`) or `MouseDrag1Border` (`resize-pane -M`) for resizing.
- **Bounce-back and non-destructive parking**: Record `@ide_last_pane_id` alongside `@ide_last_non_ai` so `Alt+a`, `Alt+e`, and `Alt+t` bounce back cleanly (including to ad-hoc `Prefix + |` and `Prefix + -` splits). Focus switches (`ide _internal toggle` and `ide _internal show`) never re-layout or resize visible panes. Park and restore panes via `_ide_park_<role>` (`Alt+Shift+A`, `Alt+Shift+E`, `Alt+Shift+T`, `ide _internal park ai|editor|term`), restoring saved custom pane dimensions, tracking `@ide_*_parked` in `@ide_tab_*` (`#[range=user|tab_*]` bounded in `ide _internal status-click`), and keeping `unbind -n WheelUpStatus` and `unbind -n WheelDownStatus` so wheel overscroll never cycles into `_ide_park_*` windows. Never kill or respawn the AI pane on `icd` or `ide cd`; live AI CLI switching and recovery run explicitly via `ide agent [<cli>|restart]`.

## Exact session targeting and single-server Neovim RPC

- **Exact session resolution** (`tmux`): `bin/ide` must never let `tmux` guess or prefix-match a session. Automated Tmux bindings pass `'#{session_name}'`, and Editor calls go through `ide_job()` in `lua/solarized/ide.lua` (appending `$IDE_SESSION`). Interactive auto-detection resolves `$TMUX_PANE` (or the session id in `$TMUX`), verifies the server PID in `$TMUX` matches `#{pid}`, and accepts only `ide`-managed sessions (`@ide_session`, `@ide_socket`, `@ide_main_win`). Session-scoped commands (`has-session`, `kill-session`, `attach-session`, `switch-client`, `list-windows`, `show-environment`, `set-environment`) pass `-t "=NAME"`, while window or pane commands (`show-options`, `set-option`, `display-message`, `list-panes`) pass `-t "=NAME:"`.
- **Editor RPC socket ownership and recovery**: Bind `@ide_socket` (`$XDG_RUNTIME_DIR/nvim-ide-<session>.sock`) strictly inside `@ide_editor_pane` (`@ide_role=editor`) via `v()` `--listen`, `SolarizedIdeSocket` `VimEnter` in `lua/solarized/ide.lua`, and ephemeral `nvim.<pid>.*` `serverstart()` recovery in `libexec/ide_lib/nvim_rpc.py`—never claiming `@ide_socket` from `Shell`, `AI`, `:terminal`, or `:!` subshell editors. Close the Editor via stdlib `AF_UNIX` MsgPack-RPC `nvim_input` (`<C-\><C-n><Cmd>qall!<CR>`, with `--remote-send` fallback). Never remap native `:q`, `:wq`, `:qa`, or `:wqa`; workspace termination uses `:Q [name...]`, `:Quit [name...]`, `Space q`, `Alt+q`, `quit`, `qide`, or `idek`.
- **Stale working directory and FUSE mount recovery**: Never scrape AI transcripts or run polling timers. Use `opt.autoread = true` and `SolarizedAutoRead` (`BufReadPre`, `FileType`, `FocusGained`, `BufEnter`, `CursorHold`, `CursorHoldI`) to re-bind stale working directory descriptors to `vim.env.PWD`, `vim.env.IDE_WORKDIR`, or `vim.env.IDE_INITIAL_ROOT` when `vim.uv.cwd()` is `nil` or `.` diverges from `PWD` before running `silent! checktime`, wrap `vim.fs.abspath` to self-heal when `uv.cwd()` is `nil`, heal remote Editor CWDs over RPC in `bin/ide` and `v()` (`normalize_pane_cwd`), and configure `SolarizedMarkdownReadability` (`wrap`, `linebreak`, `breakindent`, `scrolloff = 0`, and count-aware `j` and `k` screen-line motion) alongside global `opt.scrolloff = 4`.
- **Test and benchmark server isolation**: Never invoke `tmux` or `bin/ide` in tests or subshells with `TMUX_TMPDIR` unless `TMUX=""`, `TMUX_PANE=""`, `NVIM_IDE_SOCKET=""`, and an isolated `XDG_RUNTIME_DIR` are set (enforced in `tests/test-helper.sh` and `tests/run.sh`). Setup modules must never hot-reload live `tmux` or `nvim-ide-*.sock` servers.

## Multi-session switcher, AI lifecycle state machine, and zero-polling status bar

- **Two-pane lazy-docking switcher** (`Alt+w`, `Space s`, `Prefix + w`, `Prefix + s`, `ide -s`, or `ide switch`): Opens the existing-directory picker (`Alt+o`, `ide -o`, or `ide dir` with `Open IDE >` prompt across `zoxide`, `ide_workspace_dirs`, `$IDE_WORKSPACE_DIRS`, `$IDE_WORKSPACE_PARENT`, and `$HOME` subdirectories with `ide _internal dir-preview`) when zero IDE sessions exist in an interactive TTY, while printing `No active IDE sessions.` when non-interactive or when `fzf` is absent (and `ide list --json` serializes the structured fleet array for programmatic inspection). `Alt+n` (`ide -n` or `ide new [name]`) provisions new workspaces via `ide_create_workspace` in `links.sh` or `mkdir` under `${IDE_WORKSPACE_PARENT:-$HOME}`, flipping cleanly with `Alt+o`. On terminals at or above `90` columns (`SIDE_BY_SIDE_MIN_COLS = 90`, stacking vertically on `80×24` per [.agents/rules/monospace-tui.md](../.agents/rules/monospace-tui.md)), streams deduplicated `CSI 2 J` metadata previews (`ide _internal session-preview`, streaming continuously only while `WORKING` and refreshing on `F12` state events) on the left and streams the highlighted workspace's ANSI viewport (`<session> · <agent> · <STATE> [PREVIEW]`) onto the right placeholder pane with zero `swap-pane` or `SIGWINCH` during browsing. Focusing the right pane via `Alt+l`, `Alt+a`, or mouse click lazily docks (`[LIVE]`) the live `@ide_ai_pane` via `swap-pane -d` under `flock` serialization, preserving custom geometry, `copy-mode` `scroll_position` (including `Alt+u` scrollback entry while docked), and zoomed Editor `winsaveview()`, and undocks cleanly on `Alt+h` or `Alt+w` close (with `Tab` multi-select, `Ctrl+y` `ide ack`, `Ctrl+o` `ide pr`, `Alt+r` `ide agent`, `Alt+n` new workspace, `Alt+o` open directory, `F1` help, `F5` reload, and `Ctrl+x` `ide quit` surfacing `@ide_quit_err` inline, all driven from `libexec/ide_lib/keymap.py`). `Alt+Shift+W` (`Prefix + W` or `Prefix + S`, `ide next`) jumps to the oldest `ATTN` blocker ahead of unacknowledged `DONE` sessions in FIFO order.
- **Context dispatch** (`ide send`): Visual `Space a` and `Space A` (`--no-focus`), normal `Space il`, `Space if`, `Space ia` (`--no-focus`), and `Space id`, cross-session `:IdeSend[!] [session]` (`--no-focus` or `--switch`), and `a` in Tmux `copy-mode-vi` (`Alt+u` or `Prefix + v`) dispatch into the AI prompt using dedicated `_ide_send_<pid>` buffers without `-w` or auto-`Enter`, stripping bracketed-paste escapes and refusing bare idle shells.
- **Deterministic hook-only AI state and per-harness keybindings**: Never use `tmux` `#(...)` status polling, `/proc` or `ps` CPU sampling, `capture-pane` regex scraping, or window-bell heuristics. Lifecycle transitions occur exclusively via `ide state <running|approval|quota|done|idle> [-m|--message <text>] [session]` (idempotently provisioned across `~/.gemini/config/hooks.json` for `agy`, `~/.claude/settings.json` for `claude`, and `~/.codex/config.toml` for `codex` alongside `alt+g` keybinding overrides in `~/.gemini/antigravity-cli/keybindings.json` and `~/.claude/keybindings.json` by `setup/modules/75-ai-hooks.sh` without symlinking mutable runtime settings; draining non-TTY `stdin`, parsing optional `{...}` JSON, ignoring `idle_prompt` reminders, downgrading `agy` `USER_CANCELED` stops to `idle`, recording `@ide_ai_msg` and `@ide_ai_state_ts`, checking `_session_has_focused_client()` and `:focus:title` so unfocused `done` sets `@ide_ai_attn=1` while foreground `approval` and `done` keep `@ide_ai_attn=0`, and firing edge-triggered `ide_notify` and `IDE_NOTIFY` banners) paired with pure-C `if-shell -F` focus auto-acknowledgment (`~/.local/bin/ide _internal ack-hook` on `pane-focus-in`, `client-session-changed`, and `client-focus-in`), guarded by `pane_has_child_procs` so an exited CLI reports `SHELL` and clears stale `@ide_ai_*` options.
- **Zero-fork C format status chrome**: Top bar and outer window titles (`[!] #{@ide_attn_summary}`) rely exclusively on native `tmux` C format variables and event-driven options (`@ide_tab_ai`, `@ide_tab_ed`, `@ide_tab_term`, `tab_zoom`, `@ide_attn_summary`, `@ide_fleet_count`, `@ide_fleet_active`, `#{scroll_position}/#{history_size}`, `#{pane_synchronized}`, SSH `#h`, and `@ide_workdir`), scaling responsively across `client_width >= 120` (full key hints), `95–119` (compact right shelf), and `< 95` (`80×24` compact tabs and `[A]`, `[E]`, `[T]` parked badges). Never spawn `tmux set-option` from Neovim edit autocmds or duplicate bottom prompt segments in the top header.

## Links, inline images, clipboard, and portable shell parity

- **Clipboard and OSC 8 hyperlinks**: Never probe `/tmp/.X11-unix/X0` or `wayland-0` when `SSH_CONNECTION`, `SSH_TTY`, or `SSH_CLIENT` is set, and never set `vim.g.clipboard` (rely on `opt.clipboard = "unnamedplus"`). `dotfiles/.tmux.conf` resets `set -g terminal-features ""`, enables `terminal-features '*:hyperlinks'` with `FORCE_HYPERLINK=1`, uses `copy-pipe-no-clear` on mouse selection, forwards `Alt+v` directly to Neovim (`@ide_is_editor`) and local `agy` panes (`@ide_is_local_agy`, preserving media paste) while filtering Wayland `wl-paste` to text MIME types elsewhere, pins `MouseDown1Pane` to `select-pane -t = \; send-keys -M`, routes `Ctrl+Click` and `Alt+Click` (`recover_split_osc8_href` in `libexec/ide_lib/links.py`) to Neovim or the browser, and records a single jump mark (`normal! m'`) before `keepjumps` edits so `Mouse4`/`Mouse5` (`<X1Mouse>`/`<X2Mouse>`, `Ctrl+O`/`Ctrl+I`) return in one step.
- **Tree-sitter Markdown navigation and capability-gated images**: `lua/solarized/links.lua` traverses the Tree-sitter AST (`inline_link`, `image`, `uri_autolink`, and `(atx_heading (inline) @h)` in `markdown`) rather than screen columns. `lua/solarized/images.lua` configures `snacks.image` with all non-image `snacks` modules disabled, `doc = { inline = true, float = false }`, `math = { enabled = false }`, `SNACKS_TMUX=false` outside `tmux`, `=session`-scoped `#{client_termtype}` and dynamic SSH `remote` detection inside `tmux`, `win_width - textoff` clamping, and silent no-op fallback on terminals without Kitty Graphics `U=1` Unicode placeholders.
- **Daemon-free VCS prompts and portable shell configs** (`.vimrc` and `.bashrc-addendum`): Keep `POWERLEVEL9K_DISABLE_GITSTATUS=true` in `.p10k.zsh`. Both Zsh (`_p9k_solarized_prompt_vcs`) and Bash (`_solarized_bash_prompt`) use single-fork `git --no-optional-locks status --porcelain=v2 --branch`, zero-fork `.git/config` forge icons (``, ``, ``, ``), and asynchronous OSC 8 `<branch>@<N>` PR and MR links (`${XDG_CACHE_HOME:-$HOME/.cache}/git-pr-prompt/*.state`). `dotfiles/.vimrc` remains a single self-contained file and `dotfiles/.bashrc-addendum` paired with `dotfiles/.config/shell/` remains zero-dependency (requiring neither Python nor Zsh, including `_hs_bash_history_widget` inline `Ctrl+r` fallback when `fzf` is absent and clean lone-file degradation).
