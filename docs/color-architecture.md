# Visual precision and semantic color architecture

All UI components across terminal emulators, shell prompts, file viewers, and editors adhere to Ethan Schoonover's Solarized Dark specification by default in 24-bit TrueColor (`COLORTERM=truecolor`), while the unified 14-slot semantic role architecture (`base03` through `red`) powers all built-in and custom user themes via `bin/theme` and `libexec/theme_lib/`.

The 14 classic daily-driver themes (`solarized-dark`, `solarized-light`, `catppuccin-mocha`, `catppuccin-latte`, `gruvbox-dark`, `gruvbox-light`, `rose-pine`, `rose-pine-dawn`, `everforest-dark`, `tokyonight-night`, `kanagawa-wave`, `dracula`, `nord`, and `onedark`) preserve strict physical hue-to-slot alignment and strictly monotonic `base03` through `base3` neutral ramps. The 8 US Holiday themes (`new-years`, `valentines`, `st-patricks`, `easter`, `independence-day`, `halloween`, `thanksgiving`, and `christmas`) keep the same AST token partitioning and pairwise semantic separation—guaranteeing `GREEN` valid commands, `YELLOW` control flow, and `RED` errors never collide and `MIX_GREEN` and `MIX_RED` retain green versus red diff polarity—while intentionally remapping high-visibility foreground slots and prompt or Tmux emblems to each holiday's signature colors.

## Higher-order architectural pillars

Nine design pillars govern syntax highlighting, Tree-sitter queries, pushdown grammars, and filesystem styling across all tools:

- **Pillar I: The 3-tier semantic color contract and canvas tranquility**:
  - **Core premise**: Highlighting is an ergonomic aid engineered to minimize cognitive load and saccadic fatigue during code reading, navigation, and review. Every palette color fulfills an invariant mental category across all programming languages, configuration syntaxes, and markup documents:
    - **Tier 1: Monotone ground (70–80% screen area) in Solarized Base0 and Base01**: Uses `#839496` and `#586E75` for standard text, variable identifiers, parameters, struct and field members, custom domain types and classes (`OrderRecord`, `Context`, `HashMap`, `Instant`, `ClusterNode`, `WorkerNode`, Java and Rust `String`), generic type parameters (`T`), dynamically typed classes and typing constructs (Python `Callable`, `Union`, `EndpointMetrics`), standard library runtime classes and constructors (ECMAScript `Date`, `Object`, `Math`, `Promise`, `Error`), built-in exceptions (`ValueError`), schema relations (SQL tables, CTEs, views, indexes), Terraform schema blocks, routine and method invocations (`printf()`, `.stream()`), symbolic operators (`+`, `-`, `*`, `/`, `=`, `==`, `<`, `>`, `?`, `:`), structural delimiters and brackets (`()`, `{}`, `[]`), upright code comments, and scope qualifiers (`context.`, `fmt.`, `std::`, `boost::`).
    - **Tier 2: Structural anchors (15–20% screen area) in Green, Yellow, Blue, and Violet**: Frames structural topology:
      - **Solarized Green**: Uses `#859900` for structural scaffolding and declarations (`package`, `func`, `fn`, `def`, `class`, `struct`, `interface`, `var`, `let`, `const`, `typedef`, `CREATE TABLE`, `DEFAULT`, `ASC`, `DESC`), reserved word operators (`sizeof`, `alignof`, `_Alignof`, `static_assert`, `_Generic`), and static primitive types and core built-in scalars (`int`, `double`, `u64`, `usize`, `bool`, `void`, SQL `VARCHAR` and `BIGINT`, Python built-in scalars `int`, `str`, `float`, `bool`, `bytes`, `list`, `dict`, `set`, `tuple`, `object`, `range`).
      - **Solarized Yellow**: Uses `#B58900` for uncontested control flow and jumps (`if`, `else`, `return`, `for`, `while`, `switch`, `case`, `select`, `defer`, `match`, `try`, `catch`, `throw`, `yield`, `await`, `CASE/WHEN`). Reserving Yellow exclusively for execution pathways ensures branch points and jump exits command immediate peripheral attention, uncontested by types, keywords, or document headings.
      - **Solarized Blue**: Uses `#268BD2` for routine and function declarations (`func New...`, `fn find...`, `def __init__`, `cleanup() {`), diff hunk headers (`@@ ... @@`), and Markdown H2 section boundaries.
      - **Solarized Violet**: Uses `#6C71C4` for declarative metadata, annotations, decorators, attributes, imports, and modules (`@Service`, `@dataclass`, `#[derive]`, `[[nodiscard]]`, `import`, `from`, `use`, `package main`, `@module`, Markdown H3).
    - **Tier 3: Values and directives (5–10% screen area) in Cyan, Magenta, and Orange**: Data values and compiler meta-instructions:
      - **Solarized Cyan**: Uses `#2AA198` for string literals, filesystem paths, unbroken escape sequences and format specifiers (`%s`, `\n`), raw backtick struct tags, and Markdown link targets.
      - **Solarized Magenta**: Uses `#D33682` for numeric literals, booleans (`true`, `false`), named `ALL_CAPS` and `iota` constants (`EXIT_FAILURE`, `MAX_BUFFER_SIZE`, `LevelDebug`), runtime environment global singletons (`console`, `process`, `globalThis`, `window`, `document`), regex literal bodies (`/^\/health[z]?$/`), and sentinel values (`nil`, `null`, `None`, `std::nullopt`, `_`, `this`, `self`).
      - **Solarized Orange**: Uses `#CB4B16` for compiler directives, preprocessor macros (`#define`, `#include`), interpreter shebangs (`#!/bin/bash`), and Markdown H1 titles.
  - **Two-tier configuration topology**: In TOML, document section headers (`[table]`, `[[array]]`) receive Solarized Blue (`#268BD2`) while internal mapping keys (`port =`, `pool.min_size =`) receive Solarized Green (`#859900`), keeping enclosing brackets (`[`, `]`, `[[`, `]]`), dots (`.`), and equals signs (`=`) in Base0 Grey (`#839496`).
  - **Temporal scalar invariance**: Unquoted TOML RFC 3339 timestamps (`2025-09-14T08:30:00Z`, `17:45:00`) belong to Solarized Magenta (`#D33682`) alongside numbers and booleans, decoupled from quoted Cyan strings.
  - **Declarative configuration continuum**: XML and HTML tag attribute names (`xmlns`, `version`, `id`, `replicas`, `lang`, `class`, `charset`, `data-status`) receive Solarized Green (`#859900`), tag delimiters (`<`, `>`, `</`, `/>`) remain in Base0 Grey (`#839496`), tag element names belong to Solarized Blue (`#268BD2`), and attribute string values remain in Solarized Cyan (`#2AA198`).
  - **Stylesheet hierarchy (CSS)**: At-rules (`@layer`, `@font-face`, `@keyframes`, `@container`, `@media`, `@supports`) belong to Solarized Orange (`#CB4B16`); optional `@container` names and units (`px`) sit in Base0 Grey (`#839496`) with dimensions in Magenta (`#D33682`). Selectors (`body`, `*`, `.card-grid`, `#dashboard-grid`) receive Blue (`#268BD2`), `&` and attribute names (`data-status` via `["@tag.attribute.css"]`) sit in Base0 Grey, attribute strings (`"healthy"`) receive Cyan (`#2AA198`), pseudo-classes and pseudo-elements (`:root`, `:hover`, `::before`) receive Violet (`#6C71C4`), property names receive Green (`#859900`), custom properties (`--color-base03`), functions (`var()`, `oklch()`, `clamp()`), and compound keywords (`auto-fill`) sit atomically in Base0 Grey, hex colors (`#002b36`) sit atomically in Magenta (`#D33682`), and leaf overrides inside compound selector blocks specify priority `>= 130`.
  - **Java Properties**: Keys (`spring.application.name`, `server.port`) receive Green (`#859900`), assignment delimiters (`=`, `:`) and interpolation wrappers and keys (`${spring.application.name}`) sit in Base0 Grey (`#839496`), numbers and booleans receive Magenta (`#D33682`), strings and escapes remain unified in Cyan (`#2AA198`), and comments (`#`, `!`) sit in Base01 (`#586E75`).
  - **Protocol Buffers** (`.proto` and `.textproto`): `syntax` and `edition` directives receive Orange (`#CB4B16`); `import` and declared `package` namespace identifiers (`telemetry.v1`) receive Violet (`#6C71C4`); `package`, structural schema keywords (`message`, `enum`, `oneof`, `service`, `rpc`, `returns`, `option`, `extend`, `reserved`, `to`, `max`, `map`, `repeated`, `optional`, `required`, `stream`, `public`, `weak`), and built-in scalars receive Green (`#859900`); `rpc` method names receive Blue (`#268BD2`); user-defined types, package qualifiers, and field identifiers sit in Base0 Grey (`#839496`); enum constants, field tag numbers, unified negative numbers (`-1`), and booleans receive Magenta (`#D33682`). In `.textproto`, message block headers (`recorded_at {`, `route_quotas <`, `metrics: [{`) receive Blue (`#268BD2`), scalar field keys (`["@property.textproto"]`) receive Green (`#859900`), bracketed extension and `Any` type URLs receive Violet (`#6C71C4`), and numbers, `inf`, `-inf`, `nan`, booleans, and enum values receive Magenta (`#D33682`).
  - **Markdown semantic architecture**: Across Tree-sitter (`@markup.heading.1..6.markdown`) and `render-markdown.nvim` (`RenderMarkdownH1..H6`, `RenderMarkdownH1Bg..H6Bg` on `base02` `#073642` with `bold = false`): H1 Orange (`#CB4B16`), H2 Blue (`#268BD2`), H3 Violet (`#6C71C4`), H4 Base1 (`#93A1A1`), H5 and H6 Base0 (`#839496`), with `#`, `>`, and `|` sigils in Base01 (`#586E75`), callouts (`[!NOTE]` Blue, `[!TIP]` Green, `[!IMPORTANT]` Violet, `[!WARNING]` Orange, `[!CAUTION]` Red—never Yellow), checkboxes (`[x]` Green, `[ ]` Base01), `pipe_table` `style = "normal"`, `cell = "raw"`, and `wrap = false`.
  - **Pure monospace typography and monochromatic chrome**: Code tokens strip bold and italic (`bold = false`, `italic = false`). Inactive `LineNr` uses Base01 (`#586E75`), active `CursorLineNr` uses Base1 Bold (`#93A1A1`) on `base02` (`#073642`), `WinSeparator` and `FloatBorder` remain in Base01, `MatchParen` uses Base1 on Base02, `Search` uses `mix_yellow`, `Visual` uses `mix_base1`, and diagnostics use Error Red, Warn Yellow, Info Blue, and Hint Cyan with `fg = "NONE"` on `DiagnosticUnderline*`.

- **Pillar II: Operational role invariance**:
  - **Definition versus invocation**: Declarations (`func Process()`) are Blue (`#268BD2`); invocations (`node.Process()`, factory calls like `NewClusterNode`, and built-ins like `panic(...)`, `make(...)`, `len(...)`, `printf(...)`) remain in Base0 Grey (`#839496`).
  - **Contextual disambiguation**: Receiver references (`this.timeoutMs`, `self.val`, `super.init()`) are Magenta (`#D33682`), while constructor delegation calls (`this(...)`, `super(...)`) are Base0 Grey; computed member keys (`[Symbol.iterator]()`, `[inspectSymbol]()`) evaluate on their native expression tiers rather than Blue; host globals (`console`, `process`, `globalThis`, `window`, `document`) are Magenta while their methods (`.log()`) are Base0; sentinels (`NULL`, `None`, `nil`, `_`, `std::nullopt`) are Magenta; and Terraform block headers (`provider "aws" {`) are Green while assignment keys (`provider = aws.west`) are Base0.

- **Pillar III: Gestalt semantic continuity and atomic compound enclosure**:
  - Strings, escapes (`\n`), format placeholders (`%s`, `:.4f`), and Go backtick struct tags remain unified in Cyan (`#2AA198`); regex bodies remain unified in Magenta with Base0 slashes and Cyan flags; compound attributes (`#[derive(...)]`, `#![no_std]`, `[[nodiscard]]`, `@dataclass`, `@Override`, `@file:JvmName`, `@available`) remain unified in Violet (`#6C71C4`); Rust lifetimes (`'a`, `'static`) remain unified in Green (`#859900`); and diff `+` and `-` lines remain unified in Green or Red.

- **Pillar IV: Navigational neutrality**:
  - Scope qualifiers (`std::`, `boost::`, `context.`, `fmt.`), shell expansion sigils (`$`, `${`, `}`, `$(...)`, `$((...))`), and interpolation delimiters (`${`, `}`, `~`, `%{`) remain in Base0 Grey (`#839496`), while HCL root scope keywords (`var.`, `local.`, `terraform.`, `data.`, `module.`) receive Green (`#859900`).

- **Pillar V: Pushdown automata state machine engineering** (`syntaxes/*.sublime-syntax`):
  - Grammars in `syntaxes/` must be 100% standalone without external TextMate `Packages/...` includes, consume opening delimiters on context push rather than trapping lookaheads, anchor indentation-sensitive statement headers with `^\s*` and `(?!\s*[=:])`, deconstruct composite operators (`2>&1`), isolate `case` arms, guard contextual keywords (`of`, `in`, `catch`, `finally`, `value`, `data`) with `(?<!\.)` and lookaheads, push autonomous expression contexts on computed `[...]`, and partition dotted TOML keys via lookaheads.

- **Pillar VI: Tree-sitter AST query hierarchy** (`dotfiles/.config/nvim/queries/` and `after/queries/`):
  - Root capture groups must align with the semantic contract; compound leaf delimiters require explicit `#set! priority 130`; canvas resets must bind to concrete Base0 captures (`@markup.raw.block`, `@variable`, `["@markup.raw.xml"]`) rather than transparent `@none`; language injections must guard on explicit attributes (`type="text/javascript"`); rogue `(#set! @capture url ...)` directives must be superseded in base `queries/<lang>/highlights.scm` without `;; extends`; never maintain both `queries/<lang>/` and `after/queries/<lang>/` for the same query file; and generic catch-all rules (`(value) @string`) must precede specialized `#lua-match?` rules in document order.

- **Pillar VII–IX: LTS currency, 4-layer terminal depth, and filesystem parity**:
  - `mise` provisions current LTS and stable toolchains; terminal surfaces preserve the 4 depth planes (Base03 ground, Base02 shelves and Base01/Base00 framing with `\uE0B1` and `\uE0B3` chevrons, Base0 monotone text and OS icon, and 8 semantic accents); and `dircolors`, `LSCOLORS="exgxfxdxcxfxfxegedabagacad"`, and `EZA_COLORS` stay synchronized across GNU and BSD `ls` and `eza` (directories Blue, executables Green, symlinks Cyan, archives Orange slot 9 `91`, media Violet slot 13 `95`, crypto keys Magenta `35`, regular files Base0).

## Tooling implementations

- **Syntect CLI viewer** (`bat` or `b`): Compiles `colors/*.tmTheme` and the 37 standalone grammars in `syntaxes/*.sublime-syntax` via `bat cache --build`; `cat` remains pure coreutils.
- **Neovim** (`dotfiles/.config/nvim/`): Uses `maxmx03/solarized.nvim` (`variant = "spring"`) across `lua/solarized/*.lua`, Native 0.11+ LSP (`vim.lsp.config`), pinned `nvim-treesitter` `main` branch (`treesitter.lua` and `setup/modules/50-nvim.sh`), `render-markdown.nvim` (`Space m`), `snacks.image` (`images.lua`), and `mini.files` (`Space e` and `Space E`).
- **Shells and terminal profiles**: Powerlevel10k (`dotfiles/.p10k.zsh` and `p10k-*.zsh`), Zsh syntax highlighting (`zsh-highlighting.zsh`), portable Bash (`dotfiles/.bashrc-addendum` and `bash-*.sh`), Ghostty (`dotfiles/.config/ghostty/config`), GNOME Terminal (`colors/gnome-terminal-solarized.dconf` and `bin/gnome-terminal-solarized`), and macOS Terminal (`colors/Solarized-Dark.terminal` and `bin/macos-terminal-solarized`).
